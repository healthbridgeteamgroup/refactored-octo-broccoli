# Health Bridge Team Website

Static Cloudflare Pages website using the supplied Health Bridge Team logo.

Included: Home, About, Programs, Events, Membership application, Members Login, Member Dashboard, Contact.

Membership application: opens an email addressed to healthbridgegroup@outlook.com with the entered application details. No data is stored by this static version.

Login: demo interface only. Do not collect real passwords until secure authentication is connected.

The information architecture is inspired by the requested MDS-style professional society flow (public site -> membership -> member login), while the Health Bridge branding/content is original.
